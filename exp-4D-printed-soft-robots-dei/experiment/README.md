# 4D Printing Virtual Lab - Directory Reference

This directory contains assets and files specific to the 4D Printing Technology Virtual Lab (Experiment 9: 4D-Printed Soft Robots). The five sub-calculators run one soft-robot capability each — pneumatic bending, shape-memory stiffness locking, friction-asymmetry crawling, three-finger grasping, and closed-loop PID bending control.
