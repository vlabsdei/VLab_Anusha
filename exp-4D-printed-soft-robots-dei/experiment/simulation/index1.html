Sub-calc B · 4D Lock-and-Hold

Stiffness Switching

The real 4D trick: bend the finger warm (soft), cool it below T_g to vitrify (E jumps 100-1000×), then release pressure. If it crossed T_g the shape holds at zero actuation energy; if it stayed warm it springs straight back.

Live Insight: Set the hold temperature and material, then run the cycle to see whether the finger locks its bent shape or springs back.
