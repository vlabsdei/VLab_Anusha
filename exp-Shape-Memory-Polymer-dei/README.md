### About the Experiment 
This experiment allows students to simulate the thermodynamic and viscoelastic properties of Shape Memory Polymers (SMPs), exploring the Williams-Landel-Ferry (WLF) equation, strain fixity, entropic recovery, and multi-shape phase separation.
